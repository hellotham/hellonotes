# Syncing

Your notes are files, so anything that syncs files syncs HelloNotes.

## iCloud Drive and friends

Put the folder in iCloud Drive, Dropbox, or any File Provider and it works —
including notes that have not been downloaded yet, which HelloNotes fetches when
you open them rather than pulling your whole vault onto the device.

## Git

The **Git** row at the top of the sidebar is for the collection you have
selected: its branch, a dot when there are changes, and commit — with push and
fetch once the repository has a remote — or, for a folder that is not a
repository yet, a button that makes it one. Each note's versions are under
**History** in the panel. Commit and push from inside the app, or don't — it is
your repository. (A collection from one of the cloud accounts below is the
provider's to keep, so with one selected there is no Git row.)

## Cloud accounts

You can also connect Dropbox, OneDrive, Google Drive or Box directly, without a
local sync client. Those are your accounts; HelloNotes just reads and writes the
folder you point it at.
