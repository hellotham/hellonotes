# Transclusion

`![[Note]]` embeds another note's content inline — the real thing, rendered
here, not a copy.

A whole note:

![[Examples/Nested Note]]

You can embed a single section with `![[Note#Heading]]`, which is how a manual
page can quote one part of a longer reference without duplicating it.
