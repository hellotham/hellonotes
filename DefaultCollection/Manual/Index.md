## Keyboard shortcuts

### Files

| | |
|---|---|
| ⌘N | New Note |
| ⌥⌘N | New Window |
| ⇧⌘T | Today's Note |
| ⌃⌘N | New Note from a Prompt… |
| ⌘O | Open… |
| ⌃⌘K | Quick Capture… |
| ⇧⌘O | Open Quickly… |
| ⌥⌘R | Rescan Collection |
| ⇧⌘R | Rename… |
| ⌘D | Duplicate |
| ⌃⌘D | Move to Trash |
| ⌘P | Print… |

### Editing

| | |
|---|---|
| ⌘B | Bold |
| ⌘I | Italic |
| ⇧⌘7 | Bulleted List |
| ⇧⌘9 | Numbered List |
| ⌘F | Find… |
| ⌥⌘F | Search All Collections |

### Views and tools

| | |
|---|---|
| ⇧⌘P | Command Palette… |
| ⇧⌘G | Graph View |
| ⇧⌘J | Ask Library |
| ⇧⌘A | Assistant |
| ⇧⌘L | Review Links… |

> [!note] On iPhone and iPad
> The same commands live in the toolbar and the ⋯ menu. A hardware keyboard
> gets the shortcuts above. Formatting is on the bar above the keyboard — the
> floating shortcuts row on iPad, its own bar on iPhone — and appears whenever
> there is a cursor, in any editing view.
