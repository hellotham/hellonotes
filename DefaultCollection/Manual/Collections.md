# Collections

A **collection** is a folder you chose. HelloNotes reads and writes the files in
it and stores nothing of its own inside — no database, no index files, no
sidecar directories.

## Opening one

**File ▸ Open…** (**⌘O**) and pick a folder. Several can be open at once; each
gets a root in the sidebar.

## This collection

The one you are reading ships with the app so there is something to explore on
first launch. **You can close it** from the sidebar like any other, and reopen
it later with **File ▸ Open Default Collection**, which restores it if the files
are gone.

## Closing one

Closing a collection removes it from the sidebar. **It does not delete
anything** — the folder and its files stay exactly where they are.
