# Quarterly numbers

Nothing surprising this quarter, which is itself the surprise. Growth is flat
against a plan that assumed flat, and churn is down for the second quarter
running.

The one thing worth an argument is the support cost per account, which has been
climbing since we changed the onboarding flow.

| Quarter | Accounts | Churn | Support cost |
| --- | ---: | ---: | ---: |
| Q1 | 1,204 | 3.1% | $4.10 |
| Q2 | 1,266 | 2.8% | $4.90 |
| Q3 | 1,281 | 2.4% | $6.20 |
